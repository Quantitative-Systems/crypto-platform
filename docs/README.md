# Quantitative Platform Documentation (`docs/`)

This directory houses the comprehensive architectural, operational, security, audit, and research manuals for the Quantitative Crypto Trading Platform.

---

```text
docs/

│   ├── OPERATING_PLANES.md        # Operating planes (Data, Model, Decision, Execution)
│   └── PRODUCT_CAPABILITY_MATRIX.md # Matrix of platform capabilities & horizons
├── operations/                    # Deployment & Runtime Operations
│   ├── DEPLOYMENT_GUIDE.md        # Production & local deployment runbook

│   ├── OPERATIONS.md              # 24/7 autonomous operations SOP
│   ├── PAPER_TRADING.md           # Shadow & forward paper trading guidelines
│   └── RISK_MANAGEMENT.md         # Capital gating & risk firewall specifications
├── security/                      # Platform Security & Non-Custodial Policies
│   ├── PUBLIC_REPOSITORY_SECURITY_POLICY.md # Open-source security & IP safeguards
│   └── SECURITY.md                # Security policy & vulnerability reporting
├── audits/                        # Independent & Readiness Audits
│   ├── IMPLEMENTATION_AUDIT.md    # Codebase implementation verification
│   ├── LIVE_CANARY_FINAL_AUDIT.md # Final canary deployment audit
│   ├── LIVE_CANARY_READINESS_REPORT.md # Canary gate readiness certification
│   ├── LOCAL_PRODUCTION_READINESS_REPORT.md # Production readiness assessment

└── research/                      # Methodology & Strategy Lifecycle
    ├── RESEARCH_METHODOLOGY.md    # Multi-timeframe research standards
    ├── RESEARCH_STATUS.md         # Platform milestone progression
    └── STRATEGY_LIFECYCLE.md      # Idea -> Discovery -> Paper -> Live lifecycle
```
