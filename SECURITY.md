# Security Policy

## Supported Versions
Currently, the platform is in active research and development. There is no official production release. Use the codebase strictly for research and testing environments.

## Reporting a Vulnerability
If you discover a vulnerability that affects the deterministic nature of the platform, the structural integrity of the execution layer, or exposes sensitive configuration/credentials:

1. **Do not open a public issue.**
2. Send an email to the repository maintainers with a detailed description and steps to reproduce.
3. Allow reasonable time for analysis and remediation before any public disclosure.

## Disclaimer
**This software does not claim profitability and is NOT production-ready.**
Do not connect live exchange API keys with withdrawal permissions. Run execution engines strictly in testnet or simulated paper-trading environments until you have independently verified robustness.
